# SaShaktAI Product Constitution

## Product
SaShaktAI is an AI-powered companion designed to help senior citizens
remain independent while keeping trusted family members informed and
providing human escalation when AI is not sufficient.

## Primary User
Senior citizens living independently (Persona: Eleanor, Age 78).

## Secondary User
Trusted family members / caregivers (Sarah - Daughter, David - Son, Nurse Jenkins).

## Core Problem
Seniors often face multiple small but consequential problems:
- understanding documents
- identifying suspicious communications
- remembering appointments
- arranging transportation
- communicating with family
- knowing when they need human assistance

Existing digital products often require seniors to navigate multiple
applications and interfaces.

## Core Promise
"One simple place to ask for help, understand what's happening, and take
the next safe action."

## AI Superpower
SaShaktAI combines:
- voice understanding
- visual understanding
- user context
- risk assessment
- decision support
- action orchestration
- caregiver escalation

## Core AI Loop
```text
UNDERSTAND → CONTEXTUALIZE → ASSESS → RECOMMEND → ACT → CONFIRM → ESCALATE IF NEEDED
```

## Product Principle
AI should reduce cognitive load, not create another complicated interface.

## Safety Principle
SaShaktAI must never present an uncertain AI result as a confirmed fact.
When confidence is insufficient:
```text
AI → explain uncertainty → ask clarification or escalate to human.
```

## AI Authenticity Principle
Never describe simulated functionality as real AI functionality.
If a capability is mocked for demonstration purposes, clearly identify it as a demo simulation.
Prioritize genuine AI interaction where technically feasible.

## MVP Golden Path
Senior presents a suspicious document.
SaShaktAI:
1. reads it
2. extracts important information
3. identifies suspicious signals
4. explains the concern in simple language
5. recommends the safest next step
6. offers to contact a trusted family member
7. logs the event

## Secondary Golden Path
Senior asks for help with an upcoming appointment.
SaShaktAI:
1. understands appointment context
2. identifies preparation requirements
3. checks transportation
4. confirms timing
5. informs caregiver
6. provides a simple spoken summary.
